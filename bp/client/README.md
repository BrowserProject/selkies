# @browserproject/selkies-client

The Selkies viewer cores of BrowserProject: `selkies-ws-core.js` (WebSocket
transport), `selkies-wr-core.js` (WebRTC transport), `clipboard-worker.js` and
their `lib/` modules, with generated `.d.ts` types. Built from
`addons/selkies-web-core` of [BrowserProject/selkies](https://github.com/BrowserProject/selkies)
at the release tag of the same version. MPL-2.0.
